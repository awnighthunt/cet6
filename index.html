Web + Local File Launcher

Link Deck

把经常一起使用的网站、本地 HTML、PDF、BAT 等文件放进同一个分组。分组名称和每个项目名称都可以随时重命名；点击一次仍会批量处理整组内容。BAT 不直接执行，只打开其所在的 Windows 资源管理器位置。

⌕

提示：首次“一键打开”多个项目时，浏览器可能拦截弹窗，请允许此页面打开多个标签页。
本地文件推荐使用相对路径（例如 ./资料/说明.pdf）；整体迁移目录后，只要结构不变仍可继续使用。BAT 会尝试交给 Windows 资源管理器打开其所在目录。

新建分组

每行一个项目，格式为「名称 | 地址」。名称可自由修改；地址支持网页、本地 file:// 路径，以及相对路径。BAT 文件不会由本页面直接执行。

本地文件写法：
绝对路径：file:///D:/工具/link-deck.html 或直接粘贴 D:\工具\link-deck.html
相对路径：./资料/说明.pdf、../公共/表格.xlsx
BAT：点击 BAT 时会尝试通过 Windows search-ms: 协议打开其所在目录，再由你手动执行。
迁移建议：需要换电脑/换盘符时，优先使用相对路径，并把本页面和资料目录一起迁移。
